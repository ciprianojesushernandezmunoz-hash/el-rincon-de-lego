#EL RINCÓN DE LEGO

##Descripción

EL RINCÓN DE LEGO es una página web dedicada a recomendar sets de LEGO. Permite descubrir diferentes temáticas, como el espacio, los vehículos, los castillos y muchas otras.

El proyecto se ha realizado utilizando HTML y CSS dentro de VSC.


##Tecnologías utilizadas
HTML
CSS
Flexbox
Media queries
Font Awesome (para la parte los iconos)
